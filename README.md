# Motion Detection System

A simple Python program that uses your computer's webcam to detect movement in real time. It compares video frames to spot motion and draws boxes around anything that moves.

## Features

- **Live Video Monitoring:** Uses your webcam to watch for movement.
- **Visual Highlights:** Draws boxes around moving objects on screen.
- **Fast and Simple:** Runs smoothly using basic image processing without complex AI models.
